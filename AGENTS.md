## What it is

A Go library that loads AsyncAPI 3 documents. `Load(path)` reads a YAML or JSON spec and every local file it references, and returns a `*Document` with servers, channels, operations and messages in document order, `$ref`s followed and message and operation traits merged. Payload and header schemas stay as ordered `*Object` trees; `Document.Resolver.Deref` follows the `$ref`s inside them.

[gen-asyncapi](https://github.com/psyb0t/gen-asyncapi) depends on it, so a change to the exported API is a change for the generator too.

## Architecture

- `document.go`: `Load` and the section loaders (servers, server variables, channels, parameters, messages, operations, replies, components), plus the exported document types. `loadSections` reads servers, then channels, then operations (they refer to channels), then components.
- `resolver.go`: `Resolver` and `Location`. Loads files on demand, caches them by absolute path, follows `$ref` chains (64 hops at most, cycles and remote URLs are errors) and walks JSON pointers.
- `node.go`: `Object` and the conversion of `yaml.v3` nodes into `*Object` (ordered keys), `[]any` and scalars.
- `traits.go`: merges message and operation traits, JSON Merge Patch style, where the target's own values always win. Top-level values from a trait are wrapped in `Located` so `$ref`s inside them resolve against the trait's file.

Data flow: `Load` → `Resolver.Document` (root file) → section loaders → `Resolver.Deref` per value → `applyTraits` for messages and operations → `*Document`.

## Stack

- Go 1.26.10 (`go.mod`), one package, `asyncapi`, at the module root.
- Errors: `github.com/psyb0t/ctxerrors` wrapping `ctxerrors/commerr` sentinels.
- YAML and JSON: `gopkg.in/yaml.v3` (JSON is valid YAML).
- Tests: `github.com/stretchr/testify`.
- Lint: golangci-lint as a `tool` dependency in `go.mod`, config in `.golangci.yml`.
- No logging: it is a library.

## Commands

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep            # go mod tidy + go mod vendor
make format         # gofmt and shfmt
make lint           # shellcheck, shfmt, go fix, golangci-lint
make test-coverage  # go test -race with a 90% coverage gate
make sec            # gitleaks, govulncheck, semgrep
make docs           # build docs/ with the GitHub Pages image
```

CI runs `make lint`, `make test-coverage` and `make sec` on every branch push. A tag waits for the tagged commit's `main` run, then cuts the release and publishes the skill.

## Project-specific landmines

- Locations are absolute file paths plus a JSON pointer. A `$ref` inside a value resolves against the file that value came from, so every loader passes the `Location` it got from `Deref` down to children with `Location.Child`. Dropping it breaks cross-file `$ref`s silently in single-file tests.
- Messages and channels are deduplicated by `Location`. Two `$ref`s to one message must yield the same `*Message`.
- An operation's channel is looked up in `channelsByLocation`, which only `channels` entries fill. A channel that exists only under `components.channels` is `commerr.ErrNotFound`.
- `Object.Keys` keeps document order and callers rely on it. Never rebuild an `Object` from a map.
